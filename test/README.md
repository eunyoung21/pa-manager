# 계약서 양식(.docx) 채우기 — 검증

계약서 문구가 바뀌면 코드를 고치는 대신 앱에서 새 양식을 올린다.
그 동작이 깨지지 않았는지 확인하는 두 가지 테스트.

빈 양식(.docx) 2개와 이미 채워진 계약서 1개가 필요하다.
(예: `D:\Downloads\광고모델계약서 양식 - 드래프터 (수정) (3).docx`)

## 1) 엔진 테스트 — index.html 안의 엔진을 그대로 실행

```
node test/contract-template.test.mjs index.html 빈양식1.docx 빈양식2.docx 채워진계약서.docx
```

확인 항목: 값 반영(이름·모델료·계약일자·연락처·주민번호·주소), 조항 본문 보존,
광고주 칸 미침범, 파트 14개 보존, `{{표시자}}` 치환(워드가 조각낸 경우 포함),
이미 채워진 칸 덮어쓰기 금지.

## 2) E2E — 실제 크롬으로 앱을 띄워 클릭

```
node test/contract-template.e2e.mjs 빈양식.docx
```

목 백엔드(get/save/pfileSave/pfileGet)를 띄우고 index.html 을 그대로 로드한 뒤
`📄 계약서 생성` → `양식 올리기` → 값 입력 → `워드 생성` 까지 실제로 눌러
내려받은 .docx 내용을 검사한다. 새로고침 후 다른 접속에서도 같은 양식이 쓰이는지(pfileGet)까지 확인.
크롬 경로는 스크립트 상단 `CHROME` 상수.
